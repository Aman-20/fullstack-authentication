# Auth App

A React app with a complete authentication flow and a vibrant, consistent UI built with CSS Modules.

## Features

- Sign up, login and logout
- OTP email verification (with resend)
- Forgot and reset password
- Navbar that changes based on login state
- Coming Soon home page
- Custom 404 page and loading animation
- Responsive layout (mobile friendly)

## Tech Stack

- React (Vite)
- React Router DOM
- CSS Modules + global CSS variables



## Routes

| Path | Page |
| --- | --- |
| `/` | Home (Coming Soon) |
| `/signup` | Sign up |
| `/login` | Login |
| `/forgot-password` | Forgot password |
| `/verify-otp` | Verify OTP |
| `/reset-password` | Reset password |
| `*` | 404 Not Found |
